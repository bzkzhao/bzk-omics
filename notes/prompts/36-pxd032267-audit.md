# Prompt 36 — `python -m bzk.audit_pxd032267`: the ten-stage audit, reading only the record (revision 3)

**Repository:** `main` at the commit adding this prompt.

**Why revision 2.** An independent checker found nine defects in revision 1.
The most serious: the ban on exploratory figures was unsatisfiable, because
the attempt-2 fixture itself carries some of them. Also, importing the gate
module loads every statistical routine at runtime. All nine are fixed below. A re-audit then found
three more, each fixed: a false docstring claim, a forbidden-token clash with an
allowed figure, and `subprocess` left open.

**What this builds.** The PXD032267 counterpart of `bzk/audit.py`: ten stages,
with stage 10 behind `--reasons`.
- **It reads the committed record and computes no statistic.** PXD032267's
  attempt 2 was final (`walk/PREREG-PXD032267-gate-attempt2.md` §5).
- **One deliberate inversion of `bzk/audit.py`:** that module derives its
  numbers at run time; this one only reads numbers already in the record.
  What it keeps from `bzk/audit.py` is the rule against restating prose
  figures. A figure that lives only in prose is `NOT_AUTOMATED`, with its
  source named and not quoted.

**Governing:**
- `bzk/audit.py`, for shape only: stages, modes, and the never-`LIVE`-without-
  verified-hashes rule (l.13–15).
- The two registrations and results, `walk/walk_PXD032267.json`,
  `walk/PXD032267-published-tables.json`, and the three PXD032267 fixtures.
- `CLAUDE.md`'s four-point close.

**Edits are limited to:**
- `bzk/audit_pxd032267.py` (new);
- `tests/test_audit_pxd032267.py` (new);
- `tests/test_tautology_sweep.py`, for classifications and the floor only.

Nothing else. **The module imports neither `bzk.audit` nor
`bzk.sources.pxd032267_gate`.** Importing either loads numpy, scipy and
`bzk.stats` at runtime. It defines its own small `Stage` and report writer.

The prompt ends at the report.

## 1. Build

### 1.1 Modes and shape

- **A local `Stage`** with the fields `name`, `mode`, `figures` (dict),
  `not_automated` (list) and `not_available` (list).
- **Modes:** `bzk/audit.py`'s, plus:
  - `NOT_AVAILABLE`: nothing committed answers the stage;
  - `NOT_APPLICABLE`: the question does not arise for this design.

  Each carries a one-line reason.
- **Labels.** Every `figures` dict derived from the attempt-2 fixture carries
  `"label"`, read from that fixture. The fixture holds 13 `label` keys:
  - top level and `consistency`;
  - `readouts.T1`: the block itself, `readout_a` and its `default_cell`,
    `readout_b` and its `secondary`, and `readout_c`;
  - `readout_d`: the block itself, `readout_a` and its `default_cell`,
    `readout_b` and its `secondary`.

  Figures from `gate_g` and the consistency checks, which carry no label of
  their own, take the top-level label.
  - Every label the module reads, at every location listed in §0.3, must
    equal the fixture's top-level `label`, or the module raises.
  - A missing label anywhere it is expected raises.
- **Hashes.** Compare digests after removing any `sha256:` prefix. Record them
  with the prefix.
- **Report.** A local writer produces `audit_PXD032267.json` and `.md`, with
  every stage's mode visible.
  - It records the sha256 of **every file read**, `walk/` files included.
  - Versions come from `importlib.metadata`, read only for this record.

### 1.3 Structurally a reader: the guard is an import whitelist

An AST test over `bzk/audit_pxd032267.py` asserts:
- **Imports are only:**
  - from the standard library: `argparse`, `csv`, `dataclasses`, `hashlib`,
    `importlib.metadata`, `json`, `pathlib`, `subprocess`, `sys`, `typing`,
    `datetime`;
  - `from bzk.sources.pride import PXD032267_SITES, PXD032267_PARAMETERS`,
    and nothing else from it, because `pride` also exposes `fetch`;
  - `from bzk.provenance.raw_store import verify`, and nothing else.

  These limits are checked by name in the `ImportFrom` nodes.
- **`subprocess` is called only with a list literal whose first element is
  the string `"git"`.** That is the commit record. Any other `subprocess` call
  fails the guard. `sys` is used only for `sys.argv`, `sys.exit` and
  `sys.stderr`; any other `sys` attribute fails the guard.
- **No `ast.Name` or `ast.Call`** of `getattr`, `eval`, `exec`,
  `__import__` or `compile`, and no import of `importlib` beyond
  `importlib.metadata`.
- **Only `Import`, `ImportFrom` and calls are checked,** never string
  constants. Fixture keys such as `"readout_d"` are data.

**A runtime check as well.** A test imports the module in a fresh subprocess
and asserts that none of `numpy`, `scipy`, `statistics` or any `bzk.stats.*`
appears in `sys.modules`. `pride` loads only `bzk.http`, `raw_store` and
`requests`, which the checker measured. Both guards are mutation-proven.

### 1.4 Tests

These run on the committed fixtures, and on synthetic twins for failure
paths. A test may import `pxd032267_gate` to cross-check the label; the module
may not. At minimum:
- every stage's mode is as §1.2 gives it;
- stage 1 raises on a twin whose marker hash differs, and `--live` records
  `ABSENT` with no store;
- a twin with the label removed at any one location raises, tested for each
  location;
- stage 8 selects exactly the claims a twin plants for (b) and (c), and always
  includes (a);
- **forbidden tokens.**
  - A *whole token* is a match bounded on both sides by a character outside
    `[0-9.eE+-]`, or by the string's ends.
  - None of these may appear as a whole token anywhere in the output (the
    attempt-1 result, l.75–85, verbatim):
    - `6.48e-06`, `1.40e-02`, `3.73e-02`, `4.82e-02`, `4.80e-02`;
    - `0.024973`, `0.012209`, `0.038545` (T2);
    - `0.009637`, `0.004869`, `0.012531` (T3);
    - `0.022283`, `0.018225`, `0.001693` (T4);
    - `0.063524`, `0.019006`, `0.001872` (T5);
    - `1.7e-04`, `2.0e-04`, `1.0e-04` (k = 3);
    - `9.7e-06`, `3.3e-05` (k = 5).
  - **`3.3e-07` is not forbidden.** It is check 2's committed k = 4 figure.
  - **p values from the record are written at full float precision, never
    rounded.** The committed T2 p rounds to the forbidden `0.024973`, and at
    full precision it is a different token.
  - The module never reads any key named `exploratory_*`.
  - The published p-values and check 2's deltas are allowed.

Mutation-prove four, with `PYTHONDONTWRITEBYTECODE=1`:
